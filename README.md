# IMRCECET–2026 Conference Website

A responsive, publication-quality conference landing page for the **1st International Multidisciplinary Research Conference on Emerging Cutting Edge Trends (IMRCECET–2026)**.

## Host / Organiser
Faculty of Engineering, Aliko Dangote University of Science and Technology (ADUSTECH), Wudil.

## Main improvements in this revision
- Side navigation is a true **slide-out drawer and is CLOSED by default**.
- Drawer closes after selecting a navigation item, clicking the backdrop, or pressing `Esc`.
- Added a compact **ADUSTECH logo rail on the side of the page** while the drawer is closed.
- Full-width modern hero with technology-grid/orbit visual language.
- Responsive design for desktop, tablet and mobile.
- Clear conference hierarchy, stronger typography and spacing.
- Added Best Paper Awards and Workshops/Tutorials sections from the supplied conference agenda.
- Added scroll progress indicator, section/page indicator, active navigation, reveal animations and back-to-top control.
- No unconfirmed dates, fees, speakers, publication partners or indexing claims have been invented; these remain clearly marked TBA.

## Logo note
The current HTML references the ADUSTECH emblem from the external image URL used in the earlier site. For a completely self-contained deployment, place an official ADUSTECH PNG/SVG in an `assets/` folder and replace the image URL in `index.html`.

## GitHub Pages
